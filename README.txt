Kartikey × Pooja

WHAT THIS IS
A single-file-style romantic proposal website with:
- Dreamy + cute + cinematic design
- CSS 3D-style avatars (no photos required)
- Delhi ↔ Pune animated route
- Snapchat-inspired beginning
- Interactive proposal buttons
- Heart/confetti celebration
- Mobile-friendly layout
- Optional synthesized ambient music (no music file needed)

HOW TO TEST
1. Extract the ZIP.
2. Open index.html in Chrome.
3. Scroll through the story.
4. Test YES and LET ME THINK.
5. Test it on your phone too.

IMPORTANT
The website uses Google Fonts loaded from the internet. Everything else is local.
The music is generated by the browser and is intentionally subtle.

HOW TO SHARE IT ONLINE
The easiest options are:
A) GitHub Pages (free):
   - Create a GitHub account.
   - Create a new public repository, e.g. "pooja-proposal".
   - Upload index.html, style.css and script.js.
   - Open repository Settings → Pages.
   - Select Deploy from branch → main → /(root).
   - GitHub will give you a shareable https://...github.io/... address.

B) Netlify:
   - Create a Netlify account.
   - Choose Add new site → Deploy manually.
   - Drag the extracted folder into the upload area.
   - Netlify gives you a public https://...netlify.app address.

HOW TO SEND TO POOJA
Do not send all the files to her if you want the experience to feel special.
First publish it using GitHub Pages or Netlify.
Then send only the final website link with a short message such as:
"Hey Pooja, I made something for you. Don't open it until you're somewhere you can smile without being judged. ❤️"

For the best effect, send the link when you know she can give it 3–5 minutes with sound on.
